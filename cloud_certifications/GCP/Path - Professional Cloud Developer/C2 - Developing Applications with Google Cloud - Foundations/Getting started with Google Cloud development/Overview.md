
# Getting Started with Google Cloud Development — Module Overview

> This module covers how to `access Google Cloud services programmatically` from your applications and scripts. You learn about `Cloud APIs`, the `Google Cloud SDK`, `Cloud Client Libraries`, and `Cloud Code` for IDE-integrated development. #GCP_Development_Tools


---

---


## 1. Module Learning Objectives

After completing this module, you'll be able to:

- understand `Cloud APIs` and how they let you programmatically include Google Cloud features in your apps
- use the `Google Cloud SDK` to interact with Google Cloud services from the command line and scripts
- leverage `Cloud Client Libraries` for an optimized developer experience using the natural conventions and styles of each supported language
- use `Cloud Code` to develop Google Cloud applications within integrated development environments (IDEs)


---


## 2. Key Tools Overview

| Tool                          | What It Is                                               | When to Use                                                                   |
| :---------------------------- | :------------------------------------------------------- | :---------------------------------------------------------------------------- |
| **Cloud APIs**                | RESTful APIs exposed by Google Cloud services            | programmatically interact with any GCP service from any language              |
| **Google Cloud SDK (gcloud)** | command-line tools for managing GCP resources            | scripting, automation, CI/CD pipelines (e.g., Cloud Build)                    |
| **Cloud Client Libraries**    | language-specific SDKs (Python, Java, Go, Node.js, etc.) | application code — provides idiomatic, language-native access to GCP services |
| **Cloud Code**                | IDE plugin (VS Code, IntelliJ) for GCP development       | local development, debugging, deploying directly from your IDE                |
