
# Adding Intelligence to Your Application

## Module Overview

- Google has developed `pre-trained machine learning models` and made them available as easy-to-use Google Cloud APIs
- with just a few lines of code, you can add `artificial intelligence` to your own application
- machine learning is about `teaching machines to recognize patterns like humans do` — e.g., even a two-year-old can distinguish between an apple and an orange, but it's difficult to teach a computer to do the same thing

### Pre-Trained ML APIs

this module explores Google's pre-trained machine learning APIs:

- **Vision API:** image recognition and analysis
- **Speech API:** speech-to-text and text-to-speech
- **Video Intelligence API:** video content analysis
- **Natural Language API:** natural language processing and understanding

### Generative AI

- **Definition:** generative AI is a type of artificial intelligence that `creates new content based on what it has learned from existing content`
- generative AI takes AI a step further beyond pattern recognition — it can `make applications more powerful` and the `development experience more efficient`
- this module introduces generative AI and explains `why developers should care about it`
