
# Developing Applications with Google Cloud — Course Overview

> This course introduces the `application development process` and services provided by Google Cloud. Learn best practices for cloud applications, how to select compute and data options to match use cases, and how to deploy, monitor, and secure your applications. #GCP_App_Development

## 1. Why Cloud Application Development?

Running applications in the cloud provides key benefits:

- **scalability**
- **high availability**
- **global access**
- **decreased operational costs**

Cloud application development involves a `multitude of processes and tools` — Google Cloud provides many services and products to `streamline the development process` and run applications efficiently and securely.


---


## 2. Course Learning Objectives

After completing this course, you'll be able to:

- learn `best practices` for application development in the cloud
- understand how to choose the appropriate `data storage option` for application use cases
- use `authentication and authorization` to secure an application
- describe use cases for the different Google Cloud `compute options` used for running applications


---


## 3. Topics Covered

- **best practices for cloud applications** — designing for scalability, resilience, and operational efficiency
- **compute and data options** — matching the right GCP services to application use cases
- **CI/CD** — Google services for `continuous integration and delivery`
- **deployment** — deploying applications to Google Cloud
- **monitoring** — monitoring applications as they run in Google Cloud
- **security** — building `authentication, authorization, and security` into applications
- **AI integration** — how Google Cloud helps you build `artificial intelligence` into your applications


---
