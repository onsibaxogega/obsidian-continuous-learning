
# Deploying Applications

## Module Overview

- to run reliable services, you must have `reliable release processes`
- when many engineers are building separate application components, it's crucial they can run `unit tests, integration tests, and other tests quickly`
- with most user-facing software, teams want to release software often with `new features and bug fixes`
- to enable `high release velocity`, build, test, and release processes must be `automated as much as possible`

### Module Learning Objectives

after completing this module, you'll be able to:

- understand the components of a `continuous integration and delivery (CI/CD) pipeline`
- build container images for your application by using `Cloud Build`
- push your images to `Artifact Registry`
