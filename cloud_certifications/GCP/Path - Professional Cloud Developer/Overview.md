
# Professional Cloud Developer — Overview

> A `Cloud Developer` designs, builds, analyzes, and maintains `cloud-native applications`. The `Professional Cloud Developer` certification validates the ability to build and deploy `scalable, secure, and highly available applications` using Google-recommended tools and best practices. #GCP_Professional_Cloud_Developer


---


## Quick Links

- [Google Cloud Professional Cloud Developer Exam](https://cloud.google.com/learn/certification/cloud-developer/)


---


## 1. Role Definition

- **Cloud Developer:** designs, builds, analyzes, and maintains `cloud-native applications`
- **Professional Cloud Developer:** builds and deploys `scalable, secure, and highly available applications` by using `Google-recommended tools and best practices`
- this certification learning path provides the `practical skills` required for this role, preparing you to successfully `design, build, and manage` cloud-native applications on Google Cloud


---


## 2. Learning Path Structure

- a curated collection of `on-demand courses`, `labs`, and `skill badges`
- focused on `real-world, applied experience` with Google Cloud technologies
- upon completion, you will be equipped with the skills validated by the `Professional Cloud Developer certification`

### Core Focus Areas

- **architecting cloud-native applications** — designing for scalability, availability, and resilience on GCP
- **utilizing generative AI APIs** — integrating Google's GenAI capabilities into applications
- **integrating services** — connecting GCP services together into cohesive application architectures
- **managing application performance** — monitoring, optimizing, and maintaining production applications
