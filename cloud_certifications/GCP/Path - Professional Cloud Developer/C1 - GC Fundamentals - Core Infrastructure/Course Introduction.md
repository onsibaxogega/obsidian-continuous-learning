
# Google Cloud Fundamentals: Core Infrastructure

## Course overview

This course provides an overview of Google Cloud, covering its core products, services, and infrastructure through a combination of videos, quizzes, and hands-on labs. The focus is on understanding the value of Google Cloud and how cloud solutions factor into business strategies.

## Google Cloud offerings

Google Cloud services can be broadly categorized as follows:

- compute
- storage
- big data
- machine learning
- application services for web, mobile, analytics, and back-end solutions

## Target audience

- solutions developers
- systems operations professionals
- solution architects planning to deploy applications and create application environments on Google Cloud
- business decision makers evaluating Google Cloud

## Prerequisites

This course has no formal prerequisites. However, familiarity with the following areas is helpful:

- application development
- Linux operating systems
- systems operations
- data analytics and machine learning

## Learning objectives

By the end of this course, you should be able to:

1. Identify the purpose and value of Google Cloud products and services.
2. Define how infrastructure is organized and controlled in Google Cloud.
3. Explain how to create a basic infrastructure in Google Cloud.
4. Select and use Google Cloud storage options.
5. Describe the purpose and value of Google Kubernetes Engine.
6. Identify the use cases for serverless Google Cloud services.
7. Combine Google Cloud knowledge with prompt engineering to improve Gemini responses.
