
# Cloud Computing Overview

The term *cloud computing* was created by the US National Institute of Standards and Technology (NIST).
Cloud computing is a way of using information technology that has five equally important traits.

## Five traits of cloud computing

1. **On-demand and self-service** — through a web interface, users get the processing power, storage, and network they require without the need for human intervention.
2. **Access from anywhere** — customers access resources over the internet from anywhere they have a connection.
3. **Resource pooling** — the cloud provider has a large pool of resources and allocates them to users from that pool, allowing the provider to buy in bulk and pass savings on to customers. Customers don't need to know or care about the exact physical location of those resources.
4. **Elasticity** — resources are flexible, so customers can scale up quickly when they need more and scale back when they need less.
5. **Pay-as-you-go** — customers pay only for what they use or reserve. When they stop using resources, they stop paying.

## Evolution of cloud computing

Cloud computing evolved through three waves:

| Wave   | Model                        | Description                                                                                                                                                                   |
| ------ | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| First  | Colocation                   | gave users the financial efficiency of renting physical space instead of investing in data center real estate                                                                 |
| Second | Virtualized data centers     | virtual devices matching physical building blocks (servers, CPUs, disks, load balancers, etc.); enterprises still maintain and configure the infrastructure                   |
| Third  | Container-based architecture | fully automated, elastic cloud consisting of automated services and scalable data; services automatically provision and configure the infrastructure used to run applications |

## Google Cloud and the third wave

Google switched to a container-based architecture after realizing its business couldn't move fast enough within the confines of the virtualization model. Today, Google Cloud makes this third-wave cloud available to its customers.
Google believes that every company, regardless of size or industry, will differentiate itself through technology — increasingly in the form of software. Great software is based on high-quality data, which means every company is, or will eventually become, a data company.
