
# Service Orchestration and Choreography on Google Cloud

## overview

- managing communication between microservices becomes challenging as applications scale in size and complexity
- an event-based architecture and google cloud managed services for application integration help address this complexity
- course covers orchestration and choreography patterns to coordinate service communication

## key services

- **workflows** — orchestrates microservices
- **eventarc** — event-driven coordination
- **cloud tasks** — managed task queuing
- **cloud scheduler** — managed cron job scheduling

## learning objectives

- describe the benefits and challenges of microservices-based architectures
- describe the advantages of event-driven applications
- identify the strengths of orchestration vs. choreography
- use workflows, eventarc, cloud tasks, and cloud scheduler to coordinate a microservices application on google cloud
