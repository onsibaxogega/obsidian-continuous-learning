
# Choreography and Orchestration


---


## Module Overview

in this module, you learn about two primary patterns for coordinating microservices: `choreography` and `orchestration`

### Topics Covered

- the **choreography pattern** — how `Pub/Sub` and `Eventarc` can help you choreograph communication between microservices; when to use Eventarc
- the **orchestration pattern** — `Workflows`, Google Cloud's orchestration service; when Workflows is the correct coordination solution
- **comparison** of use cases for choreography vs orchestration and how each pattern can be used in your applications
- **Cloud Tasks** — a service that helps you manage `asynchronous HTTP requests`
- **Cloud Scheduler** — a service for managing `scheduled jobs`
- **lab:** use all of these Google Cloud services to create a `machine learning-driven image application`
