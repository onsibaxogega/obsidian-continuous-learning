## Certs for developers:

| **Certification**                       | **Exam Code** | **Key Responsibilities**                                                                                                                                                                                                                       |
| --------------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Azure Developer Associate**           | *AZ204*       | ❇️ Develop Azure compute solutions<br>❇️ Develop for Azure storage<br>❇️ Implement Azure security<br>❇️ Monitor, troubleshoot, and optimize Azure solutions<br>❇️ Connect to and consume Azure services and third-party services               |
| **DevOps Engineer Expert**              | *AZ400*       | ❇️ Configure processes and communications<br>❇️ Design and implement source control<br>❇️ Design and implement build and release pipelines<br>❇️ Develop a security and compliance plan<br>❇️ Implement an instrumentation strategy            |
| **Azure AI Engineer Associate**         | *AI102*       | ❇️ Plan and manage an Azure Cognitive Services solution<br>❇️ Implement Computer Vision solutions<br>❇️ Implement natural language processing solutions<br>❇️ Implement knowledge mining solutions<br>❇️ Implement conversational AI solutions |
| **Azure Cosmos DB Developer Specialty** | *DP420*       | ❇️Design and implement data models<br>❇️ Design and implement data distribution<br>❇️ Integrate an Azure Cosmos DB solution<br>❇️ Optimize an Azure Cosmos DB solution<br>❇️ Maintain an Azure Cosmos DB solution                              |
